# DNA-Intron-Removal

A simple Python script that removes introns from a DNA sequence using their start and end positions.

### Requirements
- Python
- NumPy
- IO

### Input Files
- `genomic_dna.txt`: Contains the DNA sequence.
- `introns.txt`: Contains intron start and end positions separated by commas.

### How to Run
```bash
run the DNA_without_introns.py


### Output
Prints the DNA sequence after removing the introns.
